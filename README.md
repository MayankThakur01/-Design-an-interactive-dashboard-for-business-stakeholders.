📊 HR Analytics Dashboard

An interactive HR Analytics Dashboard designed to analyze employee attrition and workforce trends. This project helps HR teams understand key factors affecting employee turnover through dynamic visualizations and KPIs.

🚀 Features
Employee Count
Attrition & Attrition Rate
Average Age, Salary & Years at Company
Attrition by Education
Attrition by Age Group
Attrition by Salary Slab
Attrition by Job Role
Department & Gender Slicers for interactive filtering
🛠️ Tools Used
Power BI / Excel
Pivot Tables
Data Cleaning & Transformation
Data Visualization
📈 Dashboard Insights

The dashboard highlights attrition patterns across different departments, education levels, salary ranges, and job roles, enabling data-driven HR decisions.
